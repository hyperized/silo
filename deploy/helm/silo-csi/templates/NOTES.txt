Note: the node plugin needs the kernel nbd module on each host. It drives the
kernel's NBD interface directly, so no nbd-client is needed. Load the module
with:
  modprobe nbd

Volumes survive silod restarts: while silod is briefly away (a rolling
restart, an upgrade), a volume's I/O pauses and resumes. The pause is bounded
by {{ .Values.silod.nbdReconnectTimeout }} (silod.nbdReconnectTimeout).
